# Value Proposition?

*This note acts as the basis to design materials to attract investors who want to contribute time and/or resources to develop this project*

Developing UserX as a p2p social network provides multiple paths for economic value creation and capture.

## User choice matters

**Why a QnA social network** 
*Agentic possibilities* 

- A question and answer app has user engagement built in (not just attention)
- User has control over what data to expose, and to whome, 
- QnA with multi-interface design provides unique opportunities for marketing and polling, and for recommendation engines to get real user data
- Easily integrate into future agentic networks and web3 payment platforms
    - Ability for a user to create an agent quickly is a marketed goal of the platform.

## Why invest in p2p infrastructure?

- Peer-to-peer has the problem of new technology, you need a lot of buy-in before the technology provides value,
- There are multiple projects and an evolving ecosystem,
- Web3 is based on that, 
- Provides security and privacy by default
- A p2p network can have sybil-vetted continents, with direct initiation records built into the infrastructure.

### Trusted network model (sybil-safe)
- Initial peer the user join in can be recorded, and vetted
- User can set other trusted contacts to build a trusted network

### Use case examples for a p2p infrastructure

- p2p Uber/Instacart that provides a free basic matching tier,
- Craigslist style listing service
- Second-hand items marketplace
- Tool or art-lending/sharing sevice (economic value in logistics and insurance/trust)

## Built-in attention buy-in
*Can be plugged into existing ad networks directly*

- Regular social media attention values also exist,
- With user ownership of the infrastructure, users become investors themselves as value of user's time is shared with the user directly (Via token based buy-sell)

### Token based economics

- Tokens can be used for voting, and buying user agents/attention
- Ex: memeball, each ad meme shown will give user a token.
- anyone can bid tokens to show users, and 1 - bid-value will be the platform/infrastrure fee.
